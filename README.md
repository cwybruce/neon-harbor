Neon Harbor is an original top-down 2D open-world crime game set in a neon port city at night: drive cars and boats, steal vehicles, dodge police on land and water, and run four smuggling jobs for fixer Mira. Vanilla canvas, no libraries, no network calls.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in your browser.

## How to play

- WASD / arrow keys — move, drive, and sail
- E — enter / exit a car or boat
- Mouse aim + click — shoot the pistol
- F — punch
- P — pause, G — save, L — continue, M — mute
